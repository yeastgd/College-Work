# Arithmetic (Lab 1, Q5)

### Task Description
Practice variable declaration, initialization, and basic arithmetic operations (addition, multiplication, division) in Java.

### Key Learning Point
To get a decimal output in division (e.g., `3.0`), at least one of the numbers must be a `double`, or the result must be stored in a `double` variable after a proper calculation.

### Sample Output
```text
Addition: 30
Multiplication: 150
Division: 3.0
