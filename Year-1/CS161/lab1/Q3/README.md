# What is the Output (Lab 1, Q3)

### Task Description
Predict and verify the output of different `System.out.println` statements involving strings and numbers.

### What I learned
This task demonstrates **operator overloading** for `+` in Java:
- **String literals:** Text inside `" "` is printed literally.
- **Addition:** Numbers are summed mathematically.
- **Concatenation:** If a string is involved, the `+` operator joins the elements together as text.

### 📤 Final Output
```text
5 + 6
11
56
