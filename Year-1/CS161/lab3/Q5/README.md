# Prime Number Checker (Lab 3, Q5)

Write a Java program that uses a while loop to determine if a positive integer number is a prime number. A number is prime if it is divisible **only** by 1 and itself. For example, 13 is prime but 12 is not (divisible by 1, 2, 3, 4, 6 and 12).

> **Note:** Please use an int called **num** when storing your initial value.

### Sample inputs/outputs
| Input (num) | Output |
| :--- | :--- |
| 13 | 13 is a prime number |
| 12 | 12 is NOT a prime number |
