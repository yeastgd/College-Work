# Divisors (Lab 3, Q4)

Write a Java program that uses a for loop to print all of the divisors of a given number. You should print your answer as a comma separated list.

> **Note:** Please use an int called **num** when storing your initial value.

### Sample input/output
| Input (num) | Output |
| :--- | :--- |
| 24 | 1,2,3,4,6,8,12,24 |
