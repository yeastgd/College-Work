# Strings 1 (Lab 4, Q1)

## Task Description
Write a Java program that performs the following sequence of operations:
1. Initialize a String with the value `"Computer Science"`.
2. Initialize a String with the value `"Education"`.
3. Extract the word `"Science"` from the first string using the `.substring()` method.
4. Form a new String `"Science Education"` by concatenating the extracted word with the second string.
5. Display the result.

> **Note:** The final output must be achieved through string manipulation, not by simply printing a hardcoded string.

## Sample Output
```text
Science Education
