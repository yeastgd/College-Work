# Leap Years (Lab 2, Q5)

Write a Java program with two int variables, **year** and **month**. The program should print out how many days are in that month in that year.

**Hint:**
A year is a leap year if it is divisible by 400 or if it is divisible by 4 and not divisible by 100. So, 1900 was a not a leap year, but 2000 and 2004 were.

You also need to print an appropriate message if the month is invalid.

> **Note:** You must use the variable names given. Declare and initialise year and month on separate lines. Your output must match EXACTLY.

### Sample inputs/outputs
| Input | Output |
| :--- | :--- |
| 2023, 10 | In October 2023 there were 31 days |
| 2023, 13 | Not a valid month |
